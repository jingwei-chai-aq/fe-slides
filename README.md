# fe-slides

**AQX Trader Frontend — Onboarding.** A self-contained, single-file slide deck
introducing the frontend stack.

## 🔗 Live

**https://jingwei-chai-aq.github.io/fe-slides/**

## What's here

- `index.html` — the entire deck. Fully self-contained (styles and scripts
  inlined; the only external dependency is Google Fonts). Open it locally in a
  browser or view the live link above.

## Publishing

Served by GitHub Pages from the `main` branch root. Push to `main` and the site
redeploys automatically — no build step.
